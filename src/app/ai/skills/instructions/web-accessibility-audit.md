Build and review against WCAG 2.1 AA. Check: color contrast, keyboard navigation, visible focus states, ARIA roles and labels, heading order, link/button semantics, form labels and errors, touch-target size, and reduced-motion support.

Audit the affected surfaces before shipping and produce prioritized, remediation-ready fixes with code-level corrections. Do not ship components that fail basic accessibility (missing labels, unkeyboardable controls, insufficient contrast).

Accessibility is a requirement, not a final polish pass.
